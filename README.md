# 🌸 flowerial — Prison Life Utility Hub
flowerial — клиентский Lua-скрипт (UI-хаб) для игры Prison Life в Roblox, созданный в стиле вайбкодинга. Скрипт предоставляет набор утилит: ESP для отслеживания игроков по командам, Aimbot с проверкой видимости и FOV, а также различные читы на передвижение и музыку.
Скрипт полностью адаптирован под дизайн оригинального хаба Flowerial Blade Ball, но вся логика авто-парирования заменена на функционал для Prison Life.
📋 Основные функции
1. 👁️ ESP (Подсветка игроков)
Позволяет видеть игроков сквозь стены с помощью Highlight. Автоматически восстанавливается после смерти/респавна игрока или смены им команды.
Guardian ESP — синяя подсветка надзирателей (Guards).
Prisoner ESP — оранжевая подсветка заключённых (Inmates).
Criminal ESP — красная подсветка преступников (Criminals).
Highlight opacity — настройка прозрачности заливки подсветки (слайдер 0–100%).
Outline only — режим «только контур» (убирает заливку, оставляет обводку).
2. 🎯 Aimbot (Автоматическое прицеливание)
Плавно наводит камеру на ближайшего врага в пределах заданного угла обзора.
Aimbot Toggle — включение/выключение.
Team check — не целиться в игроков своей команды.
Ignore prisoners — игнорировать заключённых (не целиться в них).
Wall Check (Raycast) — встроенная проверка видимости. Аимбот не целится сквозь стены, если между вами и целью есть препятствие.
Max distance — максимальная дистанция до цели (от 10 до 1000 studs).
Accuracy (Smooth) — плавность наведения (1% = очень плавно, 100% = мгновенно).
FOV — угол обзора аимбота (от 10° до 360°).
Draw FOV — отрисовка круга FOV на экране для визуализации зоны захвата.
3. 🤪 Misc (Разное / Движение)
Функции для модификации физики и передвижения вашего персонажа.
Fly (Полёт) — свободный полёт по карте. Управление: W/A/S/D + Space (вверх) / Shift (вниз).
Fly speed — скорость полёта (10–300 st/s).
Noclip (Ноуклип) — отключает коллизию (CanCollide = false) для всех частей персонажа каждый кадр. Позволяет проходить сквозь стены и объекты.
Spin (Кручение) — непрерывно вращает персонажа вокруг своей оси с помощью BodyAngularVelocity (не конфликтует с сервером).
Spin speed — скорость вращения (1–30°/кадр).
Speedhack (Спидхак) — изменяет скорость ходьбы (WalkSpeed). При выключении автоматически сбрасывает скорость на стандартные 16.
Walk speed — новая скорость (16–200 st/s).
Fling (Флинг) — толкает указанного игрока с огромной силой.
Nickname — текстовое поле для ввода точного Roblox-никнейма цели.
Fling! — кнопка применения.
4. ⚙️ Sound (Музыкальный плеер)
Встроенный плеер для воспроизведения звуков из библиотеки Roblox прямо в игре.
Sound ID — текстовое поле для ввода числового ID звука (например, 123456789).
Play — запускает воспроизведение (зацикленное).
Stop — останавливает музыку.
Bind key — система биндов. Нажмите кнопку, затем нажмите любую клавишу на клавиатуре. Теперь эта клавиша будет включать/выключать музыку даже когда интерфейс скрыт.
🎨 Интерфейс (GUI)
Дизайн полностью сохранён из оригинального скрипта Flowerial:
4 вкладки в сайдбаре: Глаз (ESP), Прицел (Aimbot), Смайлик (Misc), Шестерёнка (Sound).
Плавные анимации: появление/скрытие окна через UIScale и TweenService, перемещение индикатора вкладок.
Drag & Drop: окно можно перетаскивать мышкой за верхнюю панель (Header).
Локализация: переключатель EN / RU в правом верхнем углу переводит весь интерфейс.
Адаптивность: размер меню автоматически масштабируется под разрешение экрана (UIScale).
Toast-уведомления: статус функций отображается в нижней панели (Footer).

🛠️ Установка и запуск
Скопируйте весь код скрипта.
Откройте ваш Executor (Synapse X, Fluxus, Krnl, Wave и т.д.).
Вставьте код в редактор и нажмите Execute.
Нажмите Insert для открытия меню.
⚠️ Важные примечания
Noclip: В Prison Life сервер может пытаться принудительно возвращать коллизию. Скрипт использует RunService.Stepped для отключения CanCollide каждый физический кадр, что обеспечивает стабильную работу.
Spin: Используется BodyAngularVelocity вместо прямого изменения CFrame, чтобы избежать конфликтов с античитом сервера.
Aimbot Raycast: Проверка на стены реализована через Workspace:Raycast. Если луч попадает в стену раньше, чем в модель персонажа цели, цель игнорируется. Максимальная дистанция увеличена до 1000 studs.
Fling: Работает путём создания невидимой части с BodyVelocity, которая приваривается к цели через WeldConstraint на 0.4 секунды. Эффективность зависит от строгости серверных фильтров игры.
Очистка памяти: При нажатии кнопки Unload (вкладка ESP) скрипт корректно отключает все соединения (Disconnect), удаляет созданные объекты (Highlights, BodyMovers, Sounds) и уничтожает GUI.
